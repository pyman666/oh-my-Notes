# Operator 操作

## 搭配 motion  

> Operator + Motion = Action

- `d` 删除
    - `dd` 删除整行
    - `D`  删除从光标到行尾，相当于 d$
- `c` 修改，删除后进入插入模式。与 s 的区别在于可以配合各种 motion，如 cw
    - `cc` 修改整行最快的方式
    - `C`  删除到行尾并插入，相当于 c$ 
- `y` 复制
    - `yy` 复制整行
    - `Y`  复制整行，相当于 yy

## 普通 Operator

- `s` 删除当前字符然后开始输入，约等于 xi、cl
    - `S`  删除整行并输入，约等于 ^C
    - `3s` 删除3个文字并输入
- `o` 在当前行下方插入新行并输入
    - `O` 在当前行上方插入新行，并进入insert

- `x` 删除下一个字符
    - `X`  删除上一个字符
    - `3x` 删除3个字符

- `u` 撤销上一步操作
    - `U` 撤销整行操作

- `p` 在光标之后粘贴，光标位置基本不变
    - `P`  在光标之前粘贴，光标位置基本不变
    - `gp` 在光标之后粘贴，光标移动到粘贴内容末尾之后
    - `gP` 在光标之前粘贴，光标移动到粘贴内容末尾之后

- `>` 向右缩进
- `<` 向左缩进

- `.`      重复上一次修改
- `Ctrl-r` 重做上次撤销的操作

## substitute

格式：`:[range]s[ubstitute]/{pattern}/{string}/[flags]`

flags:
- `g`  替换当前行的所有匹配，而不是当前行第一个
- `i`  忽视大小写
- `I`  强制区分大小写
- `c`  替换前进行确认
- `n`  计数而不是替换
- `e`  没有匹配不报错
- `p`  替换后打印当前行
- `#`  替换后打印当前行，并显示行号
- `l`  替换后以 List 格式打印当前行
- `&`  沿用上次替换的 flags

- `:100,200s/word1/word2/g`  在100行到200行之间搜寻 word1 并取代为 word2 
- `:%s/word1/word2/gc`       在1行到最后1行之间搜寻 word1 并取代为 word2，并需要用户确认 
- `:%s/Vim//gn`              统计文件中所有 Vim 出现的次数（此时替换为什么无所谓，加了 n 就不会执行替换操作）

重复：
- `&`   普通模式，重复上次替换，使用默认 flags
- `g&`  普通模式，重复上次替换，使用上次 flags，作用于整个文件，等价于 `:%s//~/&`。
- `:s`  命令行，  重复上次替换，使用默认 flags
- `:&`  命令行，  重复上次替换，使用默认 flags
- `:&&` 命令行，  重复上次替换，使用上次 flags

## vimgrep

格式： `:vim[grep][!] /{pattern}/[g][j] {file}`

- `:vim /TODO/g **/*`                递归搜索 pwd 下的所有文件
- `:vimgrep /TODO/ **/*.{py,java}`   搜索 Python 和 Java 文件
- `:vimgrep /TODO/ *`                搜索当前文件所在目录
- `:vim //g ##`                      通配符 `##` 表示参数列表中的所有文件


## normal

> 格式：`:[range] normal {commands}`
> 如果是 Ex 命令（能 :xxx 执行），不需要 normal，如果是普通模式按键（不能 :xxx 执行），加上 normal
> command 配合 . 命令和宏 @{register}，效果拔群

- `:10,20normal I//`  对10～20行每一行开头加 //
- `:%normal` I//`      对整个文件每一行开头加 // 

## global

> 格式：`:[range] g[lobal][!]/{pattern}/ [cmd]`
> 范围默认 %，所以可以省略，cmd 默认 `print`，可以省略
> 结合 normal：`:[range] global/{pattern}/normal {commands}`
> normal 是执行批量 normal cmd，global 是 filter 后批量执行 Ex cmd，global+normal 是 filter 后批量执行 normal cmd

- `:g/foo/d`            找出包含 foo 的所有行，然后执行 :d
- `:g/foo/normal I//`  找出包含 foo 的所有行，然后对每一行执行普通模式的 I//
- `:g/foo/s/bar/baz/g`  匹配 foo 的行 → 把其中的 bar 替换成 baz

## 正则

> pattern 可以是正则表达式

示例： `` :%s/^\(\s\*-\s\*\)\(\S\*\)/\1\`\2\`/g ``   把所有第一个非空字符是 - 的行的 - 后面的非空字符加上\`，其中 \1\2 表示正则里第一个和第二个 group 的内容

- `\1`  捕获组
- `\zs` 替换从这里开始
- `\ze` 替换到这里为止
- `\=`  表达式替换

| 写法 | 名称         | 作用                           | 示例       | 匹配结果         |
| ---- | ------------ | ------------------------------ | ---------- | ---------------- |
| `\v` | Very Magic   | 切换到标准正则风格，减少反斜杠 | `\v\d+`    | `123`            |
| `\m` | Magic        | Vim 默认的 magic 模式          | `\mfoo\+`  | `foo`, `fooo`... |
| `\M` | Nomagic      | 大部分特殊字符恢复普通字符     | `\M[a-z]`  | `[a-z]`          |
| `\V` | Very Nomagic | **几乎全部按字面匹配**         | `\V[a-z]+` | 字面量 `[a-z]+`  |

如 `:%s/^\([^：]*\)：/-**\1**：` 与 `:%s/\v^([^：]*)：/-**\1**：` 等价，但后者更易读。

# 寄存器与宏

## Register

> 寄存器 = Vim 里存放复制、删除、修改、宏等内容的“小剪贴板”
> 一般除了 Normal Mode 指定寄存器要用 "a 这种带 " 的情况，其他如作为 Ex cmd 参数等直接用寄存器 name 如 a 就行

寄存器名字：

- `"`    默认寄存器        `yy / p 等价于 ""yy / ""p`
- `0`    最近一次yank      `"0p`
- `1~9`  删除历史          `"1p`
- `a~z`  自己指定          `"ay / "ap`
- `A~Z`  追加到自己指定    `"Ay`
- `_`    黑洞寄存器        `"_dd`
- `+`    系统剪切板        `"+y / "+p`
- `*`    系统selection     `"*y`
- `%`    当前文件名        `"%p`
- `#`    上一个文件名      `"#p`
- `.`    上一次insert      `".p`
- `:`    上一次Ex cmd      `":p`
- `/`    上一次search      `"/p`
- `=`    返回表达式结果    `"=表达式<CR>p`
- `q`    宏也是特殊寄存器                

寄存器内容：

- `@:`                 执行上一次Ex cmd
- `:let @a = ''`       清空 a 寄存器
- `:let @a = 'hello'`  把 a 寄存器设为 hello
- `:echo @a`           查看 a 寄存器内容


## Macro

> 录制一系列键盘操作，并允许我们重放这些操作，操作序列存储在指定的寄存器中

1. `q{register}`：开始录制宏，存在寄存器
2. register 中录制过程中按 q 退出录制
3. `@{register}`：重放寄存器 register 中的操作
    - `@@` 重放上一次宏操作
    - `[count]@{register}` 重放 count 次

> 常见用法：`q{register}` 录制一段操作，`@{register}` 重放，然后一直 `@@` 重放 
> 注意：`.` 命令对宏不生效，`.` 命令只记录上一次修改，而宏可能包含多次修改

# 汇总

## Ctrl 

- `Ctrl-v`  矩形选区
- `Ctrl-q`  windows 矩形选区
- `Ctrl-r`  重做上次撤销的操作，或在插入模式中使用 `<C-r>寄存器` 命令粘贴。
- `Ctrl-a`  增加数字
- `Ctrl-x`  减少数字
    - `g<Ctrl-A>` 创建递增序列
- `Ctrl-o`  跳回上一个跳转位置
- `Ctrl-i`  往前跳回来
- `Ctrl-u`  往上半页
- `Ctrl-d`  往下半页，或显示 Ex 命令补全列表
- `Ctrl-b`  往上一页
- `Ctrl-f`  往下一页
- `Ctrl-n`  插入模式下，向前搜索关键字补全
- `Ctrl-p`  插入模式下，向后搜索关键字补全
- `Ctrl-y`  插入模式下，接受弹出的补全菜单选项
- `Ctrl-e`  插入模式下，恢复补全前的文本（关闭原生补全菜单）


- `<C-w>`    插入模式删除前一个单词
- `<C-w>s`   水平切分当前窗口，新窗口仍显示当前缓冲区
- `<C-w>v`   垂直切分当前窗口，新窗口仍显示当前缓冲区
- `<C-w>c`   关闭活动窗口
- `<C-w>o`   关闭活动窗口外的其他窗口
- `<C-w>w`   在窗口间循环切换
- `<C-w>h`   切换到左边的窗口
- `<C-w>j`   切换到右边的窗口
- `<C-w>k`   切换到上边的窗口
- `<C-w>l`   切换到下边的窗口
- `<C-w>T`   把当前窗口移到一个新标签页
