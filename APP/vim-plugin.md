# 对齐：junegunn/vim-easy-align


## 常规用法

先选中要对齐的文本（Visual 模式），然后按 `ga` 就会进入交互模式，底部会提示输入分隔符。

| 模式 | 操作 | 说明 |
| --- | --- | --- |
| Normal | `ga{motion}{char}`    | 对齐当前段落 |
| Visual | 选中多行后 `ga{char}` | 对齐选中区域 |


## 指定第几个分隔符

默认对齐第一个匹配项。

| 操作 | 功能 |
| --- | --- |
| `ga=`   | 对齐第一个 `=`              |
| `ga2=`  | 对齐第二个 `=`              |
| `ga*=`  | 对齐所有 `=`                |
| `ga**=` | 对所有 `=` 交替进行左右对齐 |
| `ga-=`  | 对齐最后一个 `=`            |
| `ga-2=` | 对齐倒数第二个 `=`          |


## 调整对齐方式

进入交互模式后，可以使用以下按键调整：

| 按键 | 功能 |
| --- | --- |
| `<Enter>` | 切换左对齐、右对齐、居中    |
| `<Left>`  | 分隔符紧贴左侧文本       |
| `<Right>` | 分隔符右侧留出空格       |
| `<Down>`  | 去除分隔符两侧空白       |
| `<C-D>`   | 切换分隔符自身的对齐方式    |
| `<C-I>`   | 调整缩进方式          |
| `<C-L>`   | 设置左侧边距          |
| `<C-R>`   | 设置右侧边距          |
| `<C-U>`   | 切换是否忽略不匹配的行     |
| `<C-G>`   | 设置忽略字符串、注释等语法区域 |
| `<C-F>`   | 设置匹配行过滤条件       |
| `<C-A>`   | 设置多分隔符对齐模式      |
| `<C-P>`   | 切换实时预览模式        |


# 书签：MattesGroeger/vim-bookmarks

- `mm` 设置或取消书签
- `mn` `下个书签
- `mp` `上个书签
- `ma` `显示所有书签
- `mc` `清除当前文件所有书签
- `mx` `清除所有书签


# 文件树：preservim/nerdtree

- `<leader>tr` 打开 tree（结合具体配置）
- `a` 新建文件或目录
- `m` 移动
- `d` 删除
- `r` 重命名
- `c` 复制
